# Mak 玩家视角综合分析：真实习惯与搜索结果的分离与重合（2026-08-16）

> 问题：真实 Mak 玩家的三条中后期路线（①火炬+图书馆+采样仪 ②自毒→罂粟花田+黏液链枷
> ③暴击组件养符文之刃）与我们搜索找到的精英为何大面积分离？局外技能修正
> （如"武器+32 基础伤害"）能否抹平差距？哪些结果是玩家真的忽略了、为什么？
> 方法：观战机制验证 + CLI attrsOverride 剂量-反应实验（蛇首手杖 custom_0=32、罂粟花田 custom_0=200、
> 盗龙轿辇 custom_0=100、驼鹿角杖+side regen=32，模拟局外技能）+ L11/L14 精英场实测。

## 1. 玩家三路线的实测判决

### 路线 ① 火炬+图书馆+大气采样仪：**不构成分离，是真共识**

它本来就在我们的精英名单里：L11 收敛精英第 8（avg 0.514）；对 L14 精英场 avg **0.586**
（含对 L11 王智者杖 1.000、对天平 1.000、对永恒火炬壳 1.000）。
玩家的火炬直觉完全正确——它是"可继承（青铜件做完任务）+ 吃技能加成 + 精英级强度"的三重交集。

### 路线 ② 罂粟花田+黏液链枷"指数成长"：**机制成立，但不缺数值、缺行动权**

- 观战（对图书馆采样仪冻结壳）：23 秒内黏液链枷**零出手**——它出现在几乎每一次冻结目标列表里，
  自己被毒死。指数 × 0 出手 = 0。
- 剂量-反应（L11 精英场 5 席）：转换率 ×2（罂粟 custom_0=200）、触发 +32（蛇首手杖 custom_0=32）、
  平伤 +32（驼鹿角杖+regen=32）对赛果**全部零影响**；唯一翻转的是加防御/生存
  （恶臭干扰 0.000→0.500）。L14 全场复测：avg 0.100。

### 路线 ③ 暴击养符文之刃"指数成长"：同上，且更脆

- 观战（对黑冰冻结壳）：10 秒内符文之刃**从未挥出一次**，全员永冻。
- 盗龙轿辇满暴（custom_0=100）对赛果**零影响**；防御件（力量/无敌药水）把恶臭干扰 0.000→0.500。
  L14 全场复测：avg 0.000。

**判决：进攻向的局外数值修正救不了路线 ②③。** 它们的瓶颈不是数值而是控制抗性——
L11+ 精英场的冻结/减速/干扰密度直接消灭出手次数，指数机制连一次启动机会都得不到。
局外技能给的是"锦上添花"，而这些体系需要的是"雪中送炭"（行动权）。

## 2. 那为什么真实玩家觉得它们强？——两个胜率口径

与 L2 水蛭完全同构（全矩阵 0.815 vs 精英场 0.234）：

- **软口径**（对真实匹配环境≈全矩阵/锚点池）：指数体系虐菜效率极高，
  对"控制密度不足"的对手是毁灭性的——玩家在真实对局里得到的反馈是真实且良好的。
- **精英口径**（对收敛精英场）：同样这些卡组 0.0-0.2。

玩家没有错——他们衡量的尺子是"我遇到的人"，我们衡量的是"最优对最优"。
**能被广泛流传的玩法必然经过软环境筛选，而软环境筛不出控制型精英**
（控制卡组优势不可见、组装要求高、爽感低），却会放大指数体系的声誉。

## 3. 那为什么真实玩家不玩我们找到的精英？

1. **强度不可见性**：精英的强度在交互密度（全场充能、冻结连锁、恶臭干扰、计时窗口），
   单卡文本平平——天平"为其他物品充能 2 秒" vs 链枷"造成等量于伤害的剧毒"，
   按文本估值必然系统性低估交互件。我们自己的 12/12 + 6/6 文本协同全灭是同一偏差的 AI 版。
2. **路径依赖（继承制）**：真实游戏从 L2 的蜡烛/水蛭/火炬一路继承；
   转型冻结壳 = 放弃已投资体系 + 恰好拿到金件。我们的搜索是"自由重组"，
   玩家的问题是"从现有阵容出发的最近好解"。
3. **可获得性硬约束**：冻结控制需要冰霜之怖（Gold，L8 起）、图书馆/天平（Gold，L8 起）、
   大气采样仪（Diamond，L11 起）——**真实玩家在 L8 之前物理上不可能玩这些**，
   而火炬（青铜）/自毒（白银）在 L2/L5 就能上手。玩家习惯是可获得性筛选的合理结果。
4. 技能池偏袒：火炬（任务成长件）是吃技能加成最多且继承性最好的核心——
   路线 ① 成为中流砥柱是多重合理性的交点，不是玩家愚昧。

## 4. 对真实玩家更实用的搜索建议形式

1. **转型路线图替代孤立卡表**（各级数据已备）：
   - L2：灼烧王（蜡烛+红宝石+香炉+瓶装闪电+火焰药水，5 小件）或水蛭毒开局（软口径好，天花板低）；
   - L5：火炬任务完成 → 火炬嗅盐壳 / 自毒注射 / 碎瓶炼金炉药水装填（均可达精英）；
   - L8 转向点：火炬壳挂件换成 冰霜之怖+寒霜图腾+冰爪（冻结控制，冰霜之怖为唯一金件硬门槛）；
     自毒 → 注能自毒武器（实验体阿尔法+注能护腕，金件）；
   - L11：大气采样仪插入火炬壳（路线 ① 完全体）；或转智者杖天平（智者之杖白银 L5 可提前拿，
     天平金件 L8）；
   - L14+：智者杖家族 tech 件（勿忘死亡/恶臭蘑菇/冰霜之怖）按对手环境调整。
2. **双口径标注**：每套卡组同时给"软口径 avg"（预测对普通对手）与"精英口径 avg"（预测高端局），
   并标注天花板（"守门员：赢所有不够强的，输所有被优化过的"）。
3. **可获得性标注**：每套精英标注金/钻件数量与最早可玩等级。
4. **技能敏感度标注**：按本实验的剂量-反应方法，标注每套精英对常见技能
   （武器+X/暴击+X/再生+X）的弹性——让玩家把搜索结果映射到自己的技能池。

## 附：本实验的测量注记

- 剂量-反应走 CLI attrsOverride（meta 批量层只收展示名、不接 override——这是技能模拟只能用 CLI 的原因；
  两通道逐局一致性此前已多次验证，seed 协议相同：前半不换边、后半换边）。
- 发现这类"纯赛跑"对局存在**完全边偏差**（同一对局左右互换后 10/10 全翻转）——
  现行"左右各半"协议正好抵消，但意味着此类卡组的单次对局胜负几乎全由出手顺序决定，
  软环境下玩家感知到的"强度"有相当一部分其实是边偏差。
