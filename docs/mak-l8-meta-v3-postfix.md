## 5. 对既有结论的影响

- **仍然成立**：非传递性（注能护腕克股骨、股骨克炼金炉、炼金炉与冻结互有胜负）；
  壳收敛现象（48/134 锚点同壳）；DO 外环有效性；提议器能合成宇宙外新强卡（本轮直接合成新王）。
- **被推翻**：「遗物再生是顶级流派」（v2 王 0.933 → v3 0.326）——该结论完全建立在
  秘密配方光环（持续动态喂数值）+ 蛇怪之牙（全场幻影暴击）两个 bug 上。
  v3 σ 冠军"合法版遗物再生王"的标志性发现随之失效。
- **新结构**：减速重炮（矩阵王）× 冻结控制（实际最强）× 自毒武器（克重炮）构成新的顶层克制关系。
