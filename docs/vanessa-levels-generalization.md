## 2. 跨等级主线

1. **水系盾壳是 Vanessa 最长寿的引擎**（L5→L17 五连精英位）：L5 以带刃悬浮板为 carry 登基（σ=1）；
   L8 加潜水头盔+刺刀手枪升级为一王（avg 0.903）；L11 加钻石枪套守 σ 0.953；L14 仍以 σ 0.759 居纳什核心；
   L17 弹药双击退场后转型 吹箭枪剧毒武器，以通吃摧毁/冻结清场系的针对位守 σ 0.236。
   同一壳跨五档，每档只需替换 1–2 件当期高档位物品。
2. **烙刀双分支是白银档的等级窗口现象**：L5 两分支各自成族（加速→灼烧族 2 精英，减速→皮皮虾减速族 1 精英 1 流派），
   L8 双双降入流派层，L11+ 彻底消失——成长触发件被高等级控制密度与钻石引擎挤出，与 Mak 蛇首手杖案例同规律。
3. **摧毁机制在后期登顶**：L17 大坝（摧毁双方中小物品）一发抹掉船骸族整套引擎，
   造就"船骸族 > 水系盾/潜艇盾 > 摧毁/冻结/灼烧清场系 > 船骸族"的主克制环；鱼叉作为摧毁 tech 进入船骸族内部。
   Vanessa 的高等级对抗围绕"引擎展开 vs 引擎摧毁"展开，而非 Mak 的干扰/充能轴。
4. **减速族（皮皮虾/十手/拍立蚌/烈酒杯）是"矩阵口径陷阱"**：L14 矩阵 avg 王（十手 0.874）闭环后仅 0.368 入流派层；
   软口径（138 场）与硬口径（收敛精英场）的强度差在四档重复出现——分层纪律的必要性在 Vanessa 侧再次验证。
5. **飞行族起伏**：马龙鱼（L2 精英）→ 滑翔机冷却引擎（L5 精英）→ L8 流派 → 摩托/宠物石（L11 精英）
   → 摩托准镜/滑翔机船锚（L14 精英）→ L17 消失；每次回归都换了 carry 与增益件，引擎概念存续、具体形态不存续。

## 3. 构筑思路的等级规律

1. **L2 是真混合的数值竞速**：与 Mak L2 一王独大相反，Vanessa L2 是四环克制链（马龙鱼 > 毒须鲶 > 武士刀 > 火炮 > 马龙鱼），
   σ 覆盖 4–5 席——青铜池内毒/灼烧/武器/减速四系强度天然拉平。
2. **L5–L8 是护盾闭环的王朝**：水系标签互认（潜水头盔赋予）+ 护盾互充（龟壳/珍珠/套娃/拍立蚌/湿件战服）
   + 多重加速（潜水配重）构成攻防一体闭环，连续两档纯策略一王；carry 从悬浮板换成刺刀手枪只是"出口升级"。
3. **L11–L14 钻石件打开克制空间**：枪套（首轮加速）/船骸（水系多重）/冰山（用物即冻结）各自创造新轴，
   meta 从纯策略退回混合——L14 的 avg 王（船骸）与 σ 王（水系盾）错位是 Vanessa 独有的双王结构。
4. **L17 高原型**：点最优不可达，按家族代表报告（Mak L17 先例）；exploitability 0.061 为六档最高，
   家族级结论稳健、tech 点排名仅供参考。弹药钳制修复后旧精英 鱼叉滚石摧毁 体系瓦解，
 说明高等级弹药/光环组合对机制口径高度敏感。
5. **等级迁移规律与 Mak 一致**：原始形态跨级直移大多不成立（L2 两王形态到 L5 全靠闭环改造）；
   但进入中期后**壳的连续性**出现（L5→L8→L11→L14 水系盾逐档小改存续）——迁移的是引擎壳，不是具体阵容。

## 4. 对探测器的泛化评估

- 第二英雄全六等级复现了 Mak 侧的全部结构现象（锚点收敛假象、同壳收敛、矩阵/精英口径差、高原型边界），
  管线无需任何 Vanessa 特判——hero 参数化（elite_report/neighborhood_scan/matrix/battle）是本轮唯一管线改造。
- 变体物品的探测协议（池注入展示名 + deck 内互斥 + quest 位图 + 前端展开）从魂石单例泛化为可复用模式，
  烙刀双分支验证通过（无任何收敛卡组同带两变体）。
- 候选种子质量与 Mak 经验一致：矩阵顶 + σ 支撑 + 跨级对照组的 10–13 套候选足以让闭环覆盖最终名单；
  对照组种子的价值在于"闭环可将其修缮为新引擎"（L5 滑翔机、L17 元初体存续）或"证伪"（多数跌落）。
