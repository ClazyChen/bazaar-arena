# GDF 与 meta 两条优质阵容探测路线的系统对照（Mak L8）

> 本文汇总 2026-08 全部实证（docs/bazaar-meta-evidence.md、docs/reason-graph-proposer-investigation.md、
> out/gdf_mak_l8/mak_l8_deck_review.md 及各轮运行记录），对两条路线做优势/问题的系统对照。
> 结论先行：**两条路线不是替代关系，而是"候选供给 × 真值裁决"的互补关系**；
> 当前系统的真正瓶颈在提议器质量，而不在任何一侧的评估能力。

## 1. 两条路线的定义

| | GDF 路线 | meta 路线 |
|---|---|---|
| 搜索 | 锚点贪心：每档按内部循环赛（RR/Swiss）扩 1 件，beam 截断 | PSRO/Double Oracle 外环：对当前 meta 混合 σ 求 best response |
| 解概念 | 标量排名（RR 分） | 混合 Nash 支撑 σ + exploitability |
| 评估 | GDF 内部 Bo5 瑞士轮（进程内，有批盐、不缓存） | `bazaararena_meta` C++ 批量层：规则唯一、逐局可复现、自适应 CI、JSONL 缓存（~3.4 万局/秒） |
| 候选供给 | 搜索自身（单锚点/种子枚举） | 提议器组合：理由图挖掘引擎 + GDF topk + 多样性入池 |
| 产物 | 锚点 TSV / full topk / 搜索轨迹 | 真值矩阵、σ、精英池、克制关系 |

## 2. GDF 路线

### 优势

1. **覆盖面经实测证明**：134 锚点枚举的 topk 是当前唯一被验证能覆盖全部真值流派的候选源——
   v4 开放 DO（物品修复后口径）的真值支撑（减速重炮）经 GDF topk 提议器入池并被 validator 精确命中；
   真值矩阵 matrix_l8_v3 本身就是 GDF 枚举产物构建的。
2. **便宜且确定**：进程级并行后全锚点枚举 ~13 分钟；每锚点带完整搜索轨迹（raw/*.log），可审计。
3. **产出即合法卡组**：逐件构造天然满足槽位/尺寸约束，无需额外装配层。
4. **机制变更的近因测试床**：单锚点轨迹可以回答"某件物品在什么路径上被选中/淘汰"。

### 问题

1. **排序信号失真**：锚点内 RR 与真值 meta 胜率 Pearson 仅 +0.30（解释方差 <10%）。
   极端例：先祖墓 RR=141（最高）在物品修复后的真值矩阵（v3）avg 仅 0.326；
   智者之杖 RR=103 的锚点 top1 真值 avg 仅 0.149。
2. **路径脆弱性**：精英卡组的中间形态在 beam 中频繁断档（炼金炉 size=7 无前缀存活、快速注射系统的
   瘟疫长柄刀从未出现在任何中间档），靠"多路径汇合"偶然救回——换 seed/k 值就可能永久丢失。
3. **Bo5 抽签式淘汰**：以真值矩阵为参照的解析审计显示 Bo5 误判率平均 11.1%、19.9% 对局 >25%；
   误差沿贪心路径复利累积。
4. **收敛假象**：134 锚点中 60% 的 top1 只是"泛用壳 + 挂件"（52 个共享同一 6 件骨架），
   清单多样性远低于锚点数给人的印象；真实独立流派仅 8 类。
5. **解概念错误**：非传递环境下（上半区 1250 个 3 循环）标量排名无意义；
   GDF 无法表达"互相克制的多个流派都值得保留"。
6. **原理性盲区**：中间形态全弱且无汇合路径的组合不可达；meta 相对策略（恶臭蘑菇类）
   与摆位敏感组合（天平居中类仅占排列 7%）系统性漏检。种子模式不能弥补：
   两次 seeded GDF（恶臭蘑菇+智者之杖、魂戒+生命导体）的补全结果真值实测 avg 仅 0.130 / 0.023。

## 3. meta 路线

### 优势

1. **测量纪律**：C++ 评估层复用 GDF 物品规则代码，逐局可复现、可缓存、自适应预算；
   "先修测量再改搜索"被两次漂移事故（quest 丢弃、档位错位）验证为必要前提。
   全矩阵 8911 对无缓存 67s，评估不再是任何环节的瓶颈。
2. **解概念正确**：混合 Nash 支撑 + exploitability 直接适配非传递 meta；
   受限博弈验证 10/10 冷启动 3–5 轮收敛、真值支撑 3/3 再发现、σ 权重与全矩阵一致到小数点后三位。
3. **能合成矩阵宇宙之外的新强卡**：v4（物品修复后口径）σ 冠军冰霜之怖冻结控制
   不是任何锚点的 top1，却在精英循环赛居首（0.729）并 0.675 正面击败矩阵王股骨——
   当前实际最强卡组由提议器合成，而非枚举发现。
4. **可审计的机制资产**：理由图词元普查（强制三分类，机制通道不可能静默缺失）、
   排列约束等价类（居中类仅 7% 的量化解释）、引擎清单，都是可复用的知识层。
5. **外环成本已证廉价**：一轮完整开放 DO ~4–9 分钟（缓存复用）。

### 问题

1. **提议器是系统完备性的唯一瓶颈**（v1 教训：外环收敛 ≠ 收敛到正确 meta，
   只能在提议器可达空间内完备）。当前覆盖依赖双提议器互补，而两侧各有结构缺陷：
   - 理由图挖掘：数值核心只认字面量（使能件/公式件 core_score=0）、供能边一律 0.5、
     评分偏爱大闭包×强核心、配额从头部截断——天平/图书馆/股骨/时间之砂引擎**结构性缺席**
     （播种层 2119 对中含它们，截断后消失；无限制输出恰好 396 = 4 通道 × 99）。
   - 结果：**减速重炮、图书馆壳、天平充能三个流派完全靠 GDF topk 兜底**
     （遗物再生在物品修复后已退出精英层），而 GDF 供给本身是脆弱的（§2 问题 2）。
2. **静态先验 → 强度的转化率实测极低**：从机制阅读构造的 12 个协同假设
   （魂戒再生、火爪、日光矛、坩埚、镜子、冰霜毒爆、彩虹棱镜、先祖遗物、驼鹿再生、恶臭重炮×3）
   对真值精英 0-280 全败。理由图再精细也改不了这个事实——它的正确定位是
   提议先验/解释/约束层，不是强度预言机。
3. **工程复杂度高、已有两次实测事故**：Python 复刻规则两次漂移（quest 丢失、档位错位），
   缓存键污染过一次对照数据。纪律（"Python 不复刻规则"）是血泪换来的，新增组件必须守同样的规矩。
   （本轮 AI 审查的 probe.py 第三次犯了同类错误——智者之杖档位错位导致"低频重炮"假发现，
   靠 bazaararena_meta 复测才撤回。）
4. **结论适用范围窄**：全部结论限于 Mak L8；Vanessa/其他等级未验证；
   任务物品按等级满进度、overridable 按规则缩放，与真实对局同名物品强度可能有系统偏差
   （智者之杖敏感性是前车之鉴）。
5. **未消化的已知缺口**（v4 口径）：引擎覆盖 7/9（缺遗物再生——该流派修复后已崩盘，
   缺席属正确；缺剧毒武器核心对）；天平/图书馆注释表形态未定；
   DO 产物（σ + 精英池 + 克制关系）尚未报告化。

## 4. 对照总表

| 维度 | GDF 路线 | meta 路线 |
|---|---|---|
| 覆盖 | ✅ 实测全流派（但路径偶然） | ⚠️ 取决于提议器；当前 4 流派靠 GDF 兜底 |
| 排序/解概念 | ❌ 标量 RR，非传递下无意义 | ✅ Nash 支撑 + exploitability |
| 评估质量 | ❌ Bo5 噪声、批盐、不缓存 | ✅ 可复现、自适应、缓存、极速 |
| 发现新卡组能力 | ❌ 只能枚举已知锚点邻域 | ✅ 已合成宇宙外新强卡（v4 σ 冠军冻结控制） |
| 合法性保障 | ✅ 构造即合法 | ⚠️ 需装配层（魂石互斥曾漏到真值王） |
| 机制可解释性 | ⚠️ 仅有搜索轨迹 | ✅ 理由图/词元普查/等价类 |
| 工程复杂度 | ✅ 低 | ❌ 高（已有 3 次测量漂移事故） |
| 泛化（英雄/等级） | ⚠️ 未验证 | ⚠️ 未验证 |

## 5. 综合判断

1. **不要二选一**。GDF 的问题在"评估与解概念"，meta 的问题在"候选供给"——两者的短板
   恰好是对方的长板。当前架构（GDF 枚举作提议器之一 + meta 外环裁决）方向是对的。
2. **下一步的杠杆在提议器**，按优先级（详见 docs/reason-graph-proposer-investigation.md §3）：
   - R1 真值驱动的 BR 搜索提议器（局部/束搜索，目标 = 对 σ 加权胜率）——
     让"发现"由实测目标驱动，摆脱对 GDF 偶然路径与静态先验的双重依赖；
   - R2 理由图数值核心升级为公式 AST 静态估值（消除 core_score=0 假阴性）；
   - R3 挖掘配额改格子化覆盖（MAP-Elites 化），消除使能组合的结构性埋没；
   - GDF 加深枚举（pair-seed 等）仅作即期止血，不解决结构问题。
3. **两条路线共用的红线**：任何强度结论必须出自 `bazaararena_meta` 真值层；
   任何"文本上成立的协同"未经真值筛选不得进入报告。三次漂移事故与 12/12 证伪是这条红线的全部理由。
